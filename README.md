# ピッツェリア クロッキオ 公式サイト

1ページの静的サイト（`index.html`・`style.css`・`images/`）。ビルドは不要。

- メニューと写真は FUNFO の商品管理から取ったもの。価格は FUNFO の税抜価格に消費税10%（店内）を足した税込で表示している（総額表示）。CRM のコース・飲み放題の料金（3,500／4,500／6,000円・1,700／2,000円）も税抜（オーナー確認 2026-10-26）
- 公開先の予定：Cloudflare Pages（無料・商用可）。独自ドメインは未定のため、`index.html` の `canonical`・`og`・構造化データの URL は仮に `https://crocchio.jp/` にしている。決まったら置き換える
- 公開後、Google ビジネスプロフィールの「ウェブサイト」をこのサイトの URL に変え、Business Profile API の利用を申請し直す（Instagram の URL では自動で断られたため）
- 窯・店内・外観の写真は、オーナーが後日用意する（届いたら差し替える）
